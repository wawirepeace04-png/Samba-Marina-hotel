Samba Marina Hotel Website

A modern, responsive hotel website designed for Samba Marina Hotel. The website provides visitors with information about the hotel, accommodations, events, gallery, certifications, and a convenient booking/reservation section.

🌐 Website Features

🏨 Home Page – Attractive introduction to Samba Marina Hotel

🛏️ Accommodations – Displays available rooms and pricing

📅 Booking/Reservation – Guests can submit booking details

🎉 Events – Information and visuals for events hosted at the hotel

🖼️ Gallery – Collection of hotel, room, event, and facility images

🏆 Certifications – Displays hotel certifications and achievements

📞 Contact Section – Hotel contact information and location

📱 Responsive Design – Works on desktop, tablet, and mobile devices

🧭 Navigation – Smooth navigation between website sections

✨ Modern UI – Clean and professional hotel-focused design

🛠️ Technologies Used

HTML5 – Website structure

CSS3 – Styling and responsive layouts

JavaScript – Interactive functionality

Font Awesome – Icons

Google Fonts – Typography

🚀 How to Run the Website

Download or clone this repository.

Open the project folder in Visual Studio Code.

Open index.html.

Right-click the file and select Open with Live Server.

The website will then open in your browser.
